# client

Next.js 15 front end for resto-pro: customer menu, cart, checkout and the realtime kitchen dashboard.

See the [root README](../README.md) for setup, environment variables and the API it talks to.

```bash
cp .env.example .env.local   # sets NEXT_PUBLIC_API_URL
npm run dev                  # http://localhost:3000
npm run build && npm run start
npm run lint
```
